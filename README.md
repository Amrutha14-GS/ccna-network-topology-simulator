# CCNA Network Topology Simulator

## Overview

This project demonstrates multiple CCNA networking concepts implemented in Cisco Packet Tracer.

## Features

- VLAN 10, 20, 30
- Router-on-a-Stick
- Inter-VLAN Routing
- OSPF Area 0
- EIGRP AS 100
- OSPF-EIGRP Redistribution
- STP PVST+
- Loopback Interfaces
- Route Advertisement
- End-to-End Connectivity Testing
